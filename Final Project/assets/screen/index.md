# Shared-screen visual exploration

These are proposed illustrations, not a built interface or tested animation. Each image has a same-named `.prompt.txt` containing its exact generation prompt; the existing project storyboard was used only as a style reference.

- [Order card](01-order-card.png) — A thin base and a dark bake express an example order.
- [Flour ground](02-flour-ground.png) — Ground flour marks the first stage of the pizza.
- [Base rolled](03-base-rolled.png) — A thin pale base and rolling tube show the rolled stage.
- [Baking](04-baking.png) — The thin base browns inside an oven.
- [Finished pizza](05-finished.png) — A dark baked base shows the finished result.
- [Mill action hint](06-mill-hint.png) — The highlighted joystick is circled to grind flour.
- [Rolling action hint](07-rolling-hint.png) — The highlighted tube is rolled back and forth.
- [Oven action hint](08-oven-hint.png) — The highlighted oven and separated hand suggest holding a distance.
- [Star-score screen](09-star-score.png) — An example three-star result compares a thin base with its dark baked result; the star count is illustrative.
- [Layout A](10-layout-order-left.png) — The order sits left of the pizza, with a station hint below.
- [Layout B](11-layout-order-top.png) — The order sits above the pizza and rolling hint.

The hints are static visual sketches of intended loops, not animations. In the oven sketch, the hand appears beside the mouth and the joystick also has accent marks; these details need clarification in a working display. Layout A rearranges the station icons, so their order should be corrected if it is developed further. Player comprehension, actual screen legibility, overlapping active stations, timing and scoring remain untested.
